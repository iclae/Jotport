# Jotport

**把散落的灵感、事项和 agent 会话集中到一处。**

Jotport 是面向 macOS 的轻量块式草稿纸。每个块可以随意书写一行或多段内容，也可以关联本机终端里的 agent 会话。对话继续在终端进行，Jotport 负责记录、返回会话，以及提示哪些事情需要你的注意。

> **当前状态：项目初始化与首版规格已准备。** 尚无可运行的 app；功能实现和 macOS 12 Intel 实机验证均未开始。

## 使用方式

例如，在一个块里写下“排查按钮无响应”，再补充排查思路。点击启动按钮后，Jotport 打开预设终端和 agent，将正文预填到输入区域；由你按回车发送。之后修改笔记不会改变会话绑定。再次点击按钮返回同一会话，agent 需要输入或结果待查看时，块会提示并按规则上移。

## 首版范围

以下是计划实现的能力，详细行为和验收条件见[首版规格](docs/v1-spec.md)。

- **自由书写：** 多行文本块、自动保存、整块复制、归档、恢复和删除撤销。
- **整理与查找：** 拖动排序、块置顶、可选搜索归档内容；检索关联会话 ID。
- **终端联动：** 默认 agent 一键启动，也可从列表选择；预填正文但不自动发送。
- **稳定关联：** 区分笔记、原生会话 ID、运行实例和终端位置；重复点击返回原会话。
- **关注提示：** 显示运行、需要输入、结果待查看等状态；新的关注事件只提升块一次。
- **独立概况：** 首版显示只读的最近回复摘录，保留来源和更新时间。

| 项目 | 首版目标 |
| --- | --- |
| 平台 | macOS 12 及以上，Intel x86_64 |
| 技术 | Swift、AppKit、SQLite |
| 终端 | [Ghostty Monterey 社区版](https://github.com/laojianzi/ghostty-monterey) 1.4.0、WezTerm |
| Agent | Codex CLI、pi |
| 窗口 | 可置顶；状态更新不抢占键盘焦点 |

优先直接适配终端和 agent。只有直接方案出现可复现的接入缺口时，才评估 herdr。数据模型为网页等关联保留扩展空间；iTerm2、其他 agent、跨平台和云同步暂缓。
