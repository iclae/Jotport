# 雾白单栏测试版（build 5，取代 build 4）

基于 master 8b6b3e2 的增量界面更新。默认窗口 444 × 600 pt，可缩至 360 × 280 pt。系统原生标题栏，默认不置顶。上方仅搜索、置顶、选项和新建；无固定搜索框、统计或页脚。

点击搜索或 ⌘F 展开并聚焦；包含归档在展开区及选项菜单可达。搜索框内 Esc 在无输入法组词时清空、收起并恢复原编辑块（无原编辑块则首块）；不拦截正文编辑器 Esc。⌘N 新建，⌘, 设置，⌘H 隐藏保留。复制、归档、块置顶、拖动、会话操作及其菜单沿用现有实现；正文右键保留原生文字操作并增加块操作子菜单。结果待查看以文字按钮持续呈现，不以新事件推断状态。

使用指定雾白六色色板，深色模式采用动态系统色，不强制浅色。未改变 SQLite schema、会话启动/事件语义或用户数据。

验证：新增 AppKit 搜索展开/焦点/清空/关闭/组词保护回归测试，以及原有中文、会话 ID、归档/删除匹配测试。交付以分支 CI 的真实测试和 artifact 为准。没有连接目标 Mac：中文 IME、键盘遍历、拖动、VoiceOver、Dark appearance 和四终端/agent 组合仍需 macOS 12 Intel 实机验收；未替换用户安装或数据。

最近启动目录：在需要选路径时先显示最多 8 个有效的最近目录，按最近接受/使用排序，带完整父路径以区分同名文件夹。「使用所选目录」明确确认，「选择其他目录…」进入原生目录面板；无有效最近目录直接打开面板。首次选择、显式更改路径、失效路径替换使用同一入口。已有有效块路径不再询问。取消不改 MRU；接受并保存路径、或持久化启动请求后更新。列表仅存于 Jotport 的 UserDefaults，不读取系统最近目录、不改变发送行为。build 5 同时包含雾白界面和最近目录，替代之前的 build 4 临时包。
