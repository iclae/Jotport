# 雾白还原与交互修复（build 6）

对照来源：用户实际 Retina 截图 image(3).png、Jotport-A-四种配色.png 左上 01、Jotport-A-搜索展开.png，均已通过 Library 下载并查看原图。此前 build 5 的空窗口截图不能证明布局还原。

差异与调整：实际截图约 444×628pt，设计稿窗口约 444×325pt；原标题栏下多出一行工具，左右分散，正文左缩进约42pt。现采用原生交通灯与透明标题栏，在42pt同一横条居中显示名称、右侧排列四个工具；默认高度325pt。正文边距22pt、安静分隔线、首行17pt与后续14pt的显示层级。首行样式仅显示属性，不拆分标题字段、不改变普通文本存储或复制。搜索改为40pt单行，包含归档留在选项入口，增加明确关闭按钮并移除粗系统焦点环。

交互：放大镜再次点击关闭；⌘F保持打开并聚焦；Esc在窗口事件路由中处理，组词期间交还输入法；关闭后清空查询和归档过滤，恢复安全编辑焦点。置顶按钮根据真实窗口level同步pin/pin.fill、无障碍标签和提示，每次启动默认不置顶。

验证在macOS CI的临时SQLite与合成笔记上进行，绝不读取用户笔记。原生窗口有内容的关闭/展开搜索、置顶/取消置顶截图与接触表随CI artifact交付。CI不是Monterey目标机：实际中文输入法、VoiceOver、Spaces和真实终端组合仍需目标机验收。
