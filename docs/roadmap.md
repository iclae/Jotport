# Jotport 开发计划

本计划把[首版规格](v1-spec.md)拆为四个阶段。当前仅完成项目初始化和规格整理，以下阶段均未开始。规格中的行为和验收条件优先于本计划的概述。

## 第一阶段：验证会话接入链路

用一个可编辑文本块验证两种终端和两种 agent 的完整接入。先解决身份和输入控制，再扩展界面。

工作内容：

- 探测实际终端安装包、脚本或 CLI 能力，以及 Codex、pi 版本。
- 按预设终端、agent 和工作目录启动；保存正文快照、启动请求与原生会话 ID。
- 确认目标输入区域就绪后，原样预填多段正文，不自动提交。
- 处理重复点击、启动超时、终端关闭、运行退出，以及按会话 ID 返回或恢复。
- 记录直接适配的实际缺口；必要时按规格评估 herdr，不预先引入额外运行时。

完成条件：

- 四种组合均有可复现的启动、预填、绑定和返回结果，并记录实际版本。
- 连续点击不重复建会话；再次打开不重复粘贴；正文修改不改变绑定。
- 中文、空行、尾随换行和 shell 特殊字符保持原文，不被执行为命令。
- 状态不确定时明确显示未知或接入失败。“已打开，待粘贴”可保留为降级，但不算自动预填通过。
- 核心组合存在阻塞时先解决或明确记录，不能移除组合、提高最低系统版本或改为自动发送来通过验收。

## 第二阶段：完成草稿纸与本地保存

工作内容：

- 使用 AppKit 完成块编辑和可置顶窗口，保留中文输入法、选择及撤销行为。
- 使用 SQLite 保存正文、顺序、关联和历史 ID。
- 实现整块复制、归档、恢复、删除撤销、置顶和拖动。
- 实现搜索及“包含已归档”开关。

完成条件：

- 正常退出、重启及意外退出后，已提交数据与关联可恢复。
- 中文、多段文本、概况和会话 ID 可按规格检索。
- 归档、删除、拖动及置顶均不误终止或改变会话绑定。
- 普通桌面、多桌面和全屏行为完成目标机检查；切换终端和收到事件时不抢焦点。

## 第三阶段：完成状态与关注管理

工作内容：

- 接入 Codex hooks 和 pi 扩展，建立轻量事件桥接，保留用户现有配置。
- 区分运行状态与关注提醒，处理重复、乱序和旧运行事件。
- 实现关注上移、置顶区固定顺序，以及编辑、组词、搜索和拖动期间延后重排。
- 实现只读最近回复摘录，保存来源、轮次、时间和过期状态。
- 完成 app 重启、系统唤醒和连接中断后的状态核对，以及独立的结束 agent 操作。

完成条件：

- 多个会话同时工作时，状态、输入和终端定位不串线；子 agent 结束不误报主会话完成。
- 同一关注事件只提升一次；查看提醒不伪造 agent 已恢复运行。
- 归档会话仍有关注入口，删除块不会被迟到事件重新创建。
- 退出 app 不默认终止会话；结束操作只影响已核验的目标运行。
- 概况与正文独立；旧回复不冒充当前结果；接入配置可撤销。

## 第四阶段：目标机验收与首版交付

在 **macOS 12 Intel** 上，按[首版规格的验收条件](v1-spec.md#实现顺序与验收)逐项记录结果。静态检查不能替代目标机验证。

| 终端 | Agent | 当前状态 |
| --- | --- | --- |
| Ghostty Monterey 社区版 1.4.0 | Codex CLI | 待实机验证 |
| Ghostty Monterey 社区版 1.4.0 | pi | 待实机验证 |
| WezTerm | Codex CLI | 待实机验证 |
| WezTerm | pi | 待实机验证 |

完成条件：

- 四种组合完成启动预填、ID 绑定、重复返回、状态、排序、关闭及恢复验收。
- 公共验收覆盖中文输入、特殊字符、多会话、授权等待、异常退出、睡眠唤醒和窗口行为。
- 记录实际 `.app` 大小、冷启动时间、空闲 CPU、常驻内存和多会话资源变化。
- 提供 Intel 可运行 `.app`、源码、经过验证的构建说明，以及首次接入和撤销步骤。
- 公开列出实际版本、验证证据和仍存在的限制；不把待验证项标为已支持。

首版之后，再评估网页关联、更多 agent 和其他终端。后续范围由实际使用结果决定。
